# 第一季统一提示词与画风圣经

- 项目：`MSV-S01《魔兽视界：我的金币真的能换钱》`
- 状态：`G2 共享画风已建立；G3 双主角正脸待用户确认`
- 用途：角色基准、关键帧、首尾帧与后续图生视频的唯一统一前缀

## 共享画风

- 形式：9:16竖屏，高品质 stylized 3D 动画电影角色渲染。
- 写实度：成年二次元化面部比例，真实皮肤、发丝、布料与生活磨损；不做真人照片，也不做塑料玩具或Q版。
- 眼睛：略大于现实但保持成年感；虹膜与高光清晰，不做幼态大眼娃娃。
- 鼻唇：结构自然、不过度尖小，不使用统一网红脸。
- 头身：现实人物约7—7.5头身；游戏角色可到7.5—8头身。
- 镜头：脸部特写使用等效85mm，眼平机位，从头顶到下巴；中景等效50mm；环境全景等效28—35mm。
- 测试背景：浅暖灰纯摄影棚；剧情现实场景按已锁定光源；游戏世界为灰蓝基底与琥珀/金色魔法光。
- 布光：角色测试统一5500K柔和主光、弱补光、轻暖轮廓光；剧情光线必须有真实来源。
- 色彩：现实段落暖木色与冷屏幕蓝对比；系统为克制的透明金；游戏战斗用暗青灰、熔岩橙与危险红。
- 画面：高对比但保留暗部细节，中等景深，低颗粒，无过度锐化。

## 通用图片负向约束

```text
禁止真实游戏名称、Logo、角色、种族、职业、建筑、装备与UI；禁止可读文字、乱码、二维码、水印；禁止纹身、耳钉、耳环、项链、烟、酒、金链；禁止幼态未成年感、网红脸、同脸复制、Q版chibi、塑料玩具感；禁止畸形手脚、多指少指、多余人物、面部扭曲、穿模、漂浮物、悬空道具、比例失调、场景布局漂移、服装和发型漂移。
```

## 人物特写合同

```text
等效85mm人像焦段，眼平机位，正面或明确指定的三分之四角度；构图从头顶到下巴，几乎不露脖子，完全不露肩、手臂和腰；表情克制自然，脸型、年龄、发型、眼镜与肤色严格匹配正式角色基准图。
```

## 中景与全景合同

```text
人物完整落地并与环境有真实接触；手指、手腕、脖颈和所有可见皮肤干净无印记；衣物结构清楚；桌上物品完全接触桌面，脚底接触地面；多人身高、前后关系、视线和左右位置严格按连续性表执行。
```

## 游戏世界合同

```text
完全原创的高幻想MMORPG世界，灰蓝石材、琥珀符文灯、透明金色几何魔法界面；玩家职业轮廓、怪物、主城和图标全部原创，不复刻任何现实商业游戏；游戏界面只保留无字占位框，精确内容后期合成。
```

## 系统面板合同

```text
仅陈默能感知的金色半透明几何面板，细金线、低饱和暖金辉光、层级清楚、中央留大片可排版空白；其他人物不得注视或触碰面板；生图无字，比例、任务名、按钮和数字全部后期叠加。
```

## 通用图生视频合同

```text
基于本镜头已验收的正式首帧与尾帧生成竖屏无声视频；只发生分镜规定的一个主要动作，人物仅有自然呼吸、眨眼和必要微表情；镜头固定或只执行分镜指定的小幅运动；保持人物身份、年龄、脸型、发型、眼镜、服装、人数、场景布局、道具位置、时间与光线不变；不新增物体、不生成文字、不改变构图、不变形、不穿模；动作在时长内完成并稳定停在正式尾帧状态。
```

## 角色引用格式

每次生成必须写明：`角色名 + 正式基准图绝对路径 + 本次用途 + 当前方向`。多人镜头每人只绑定一张最匹配当前方向的正式身份参考，禁止把多张互相冲突的候选同时喂给模型。
