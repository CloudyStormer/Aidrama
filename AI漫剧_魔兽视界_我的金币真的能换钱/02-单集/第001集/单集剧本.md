# 第001集《30岁，我还在魔兽视界搬砖》制作剧本

- 版本：`v0.1.0`
- 状态：文本制作包完成，角色基准图待审批，尚未制作成片

## 单集目标

- 核心戏剧问题：陈默被现实否定到最低点时，十二年游戏热爱是否真的能产生价值？
- 本集观众回报：在“3200 金只值 96 元”的压抑现实之后，热爱系统正式激活并给出第一项可验证任务。
- 目标时长：180 秒；36 个 5 秒源镜头。
- 开场钩子：新人即将导致团灭，陈默一句指挥扭转局面，立即证明“现实失意的人在另一个世界很有能力”。
- 结尾承接：陈默接受“帮助一名新人完成首次副本”的任务，进度 0/1；下一集验证金币能否真的高倍率兑换。
- 工作假设：屏幕文字全部后期合成；本集只生成陈默、陈母两位现实人物的表演，苏晴只以消息和画外音出现。

## 制作剧本

### 场次001｜新手副本 / 陈默卧室｜深夜

- 连续性状态：陈默穿 `服装-001`，佩戴固定黑框眼镜；卧室使用 `场景-001`，游戏使用 `场景-003`。
- 戏剧目的：先证明陈默的游戏能力，再用收益数字击穿成就感。
- 出场角色：`角色-001`、`角色-配角-001`、`角色-游戏-001`。
- 关键道具：`道具-003`、`界面-001`、`界面-004`。

**可见动作**

新人站在致命技能圈边缘；陈默准确指挥其左移；Boss 倒地；新人鞠躬道谢；结算升至 3200 金；交易换算落到 96 元；陈默苦笑。

**对白**

- 陈默（语音，急而稳）：“左！现在！再晚一秒就团灭！”
- 陈默：“对，就这样，继续输出。”
- 新人：“谢谢大佬！没人肯带我这么久。”
- 陈默（轻声）：“不客气。”

**旁白/内心**

- 陈默：“九十六块……又是九十六块。”

**屏幕文字（后期）**

- “今日收益：3200 金”
- “市场比例：1 金币 = 0.03 元”
- “可提现：96.00 元”

**声音与音乐**

Boss 低吼、技能预警、通关提示、金币结算；轻电子节奏在收益换算时突然抽空，只留一次干涩确认音。

### 场次002｜陈家客厅餐桌｜深夜

- 连续性状态：`道具-001` 已在桌上，`道具-002` 屏幕初始熄灭；暖黄顶灯。
- 戏剧目的：把经济压力升级为家庭与亲密关系压力，同时用热汤证明母亲并未放弃陈默。
- 出场角色：`角色-001`、`角色-003`、`角色-002`（消息/画外音）。

**可见动作**

陈默推门；陈母叹气、比较、把热汤推过去；陈默抬眼说出“第二个世界”；陈母摇头离开；陈默眼眶发红；手机亮起；消息到达；陈默攥紧手机。

**对白**

- 陈母：“默默，你还没睡啊。你都三十了……你王叔家孩子都当总监了。”
- 陈母：“你玩了十二年了，真能当饭吃吗？”
- 陈默（小声）：“妈，这不是玩。是我的第二个世界。”
- 陈母：“唉……”

**消息/画外音（后期）**

- 苏晴：“陈默，我妈又催了。我们谈谈吧。”

**声音与音乐**

客厅夜间底噪、汤碗与木桌轻触、远处关门声、短促消息提示；温暖钢琴只留稀疏单音，不煽情。

### 场次003｜陈默卧室 / 游戏主城｜深夜

- 连续性状态：陈默外观不变；手机放在键盘左侧；系统在镜头 028 才第一次出现。
- 戏剧目的：陈默在最低点仍回到熟悉世界，系统以精确数字回应他的长期投入。
- 出场角色：`角色-001`、`角色-游戏-001`、`角色-系统-001`。
- 关键道具：`道具-002`、`道具-003`、`界面-001`、`界面-002`。

**可见动作**

陈默坐回电脑椅、双击登录；游戏主城展开；他深吸气并点击日常任务；游戏 UI 暗下，金色系统弹出；数字定格 31247；任务卡展开；陈默震惊，光标移向“接受”并点击；金光映在脸上。

**对白**

- 陈默：“再打一轮日常。”
- 系统：“检测到宿主热爱值满格。”
- 系统：“累计在线三万一千二百四十七小时。”
- 系统：“热爱系统激活。当前比例，一比零点零三。”
- 系统：“守护任务：带一名新手首次通关。奖励比例加零点一。”
- 陈默：“这……什么东西？”
- 系统：“任务已接受。”

**屏幕文字（后期）**

- “热爱值：100%”
- “累计在线：31247 小时”
- “当前比例：1 金币 = 0.03 元”
- “守护任务：帮助一名新手完成首次副本通关”
- “奖励：比例 +0.1”
- “接受 / 拒绝”
- “任务已接受｜进度 0/1”

**声音与音乐**

登录音、主城环境、鼠标双击；系统出现时低频启动音接金属电子提示，心跳在点击前渐强，结尾以一次清晰任务启动音切黑。
