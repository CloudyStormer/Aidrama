# 角色基准图

## 状态规则

- 文件名格式：`角色-编号_姓名_基准图_vNN.png`
- `待审批`：仅可用于风格试拍，不得批量扩展全季。
- `已锁定`：出品方确认后，在 `01-设定库/角色卡.md` 与 `视觉连续性.md` 记录版本和日期。
- 新版本不得覆盖旧版本；使用 `v02`、`v03` 递增。

## 本批次

- `角色-001_陈默_基准图_v01.png`：待审批
- `角色-002_苏晴_基准图_v01.png`：待审批
- `角色-003_陈母_基准图_v01.png`：待审批
- 角色-004 至 角色-007：尚未生成

每张基准图包含一个中性主视图和四个表情小视图；表情小视图只用于确认范围，后续镜头仍以同一主视图身份为锚点。

## v01 内部检查提醒

- 三张图的身份与表情一致性可用于审风格。
- 三张图都露出完整脖颈和部分上胸，没有完全执行“头顶到下巴、几乎不露脖子”的最终大头贴规则。
- 陈默与苏晴年龄感略年轻，陈母的灰发比例偏少。

因此 v01 只能作为待审批身份候选。出品方需决定：认可身份后机械裁切，或生成满足构图和年龄要求的 v02；在决定前不得升级为“已锁定”。
