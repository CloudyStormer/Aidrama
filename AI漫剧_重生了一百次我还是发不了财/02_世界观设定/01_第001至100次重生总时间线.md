# 第001至100次重生总时间线

本表是全剧轮次真源。分集、对白和镜头中的次数必须与本表一致。

## 原始人生 `T000`

林默从 2016 年 25 岁活到 35 岁，经历裁员、负债和关系破裂。一次雨夜事故后，他第一次回到 2016-07-01。原始人生不计入重生次数。

## 阶段二：共同死亡与绑定 `R017`

| 轮次 | 关键事实 | 知情状态 |
|---|---|---|
| R017 | 林默再次尝试创业，一年后失败。商场火灾中，他顺手救出陌生人苏晚。数日后，苏晚寻找他致谢，发现他准备结束本轮；她冲上去阻止，两人在同一失控车辆事故中共同死亡。林默死亡触发回档，苏晚被一同带回 2016-07-01。 | 林默只认为这又是一次普通重启；苏晚醒来后完整记得火灾、寻找、阻止和共同事故。 |

## 阶段四：隐蔽干预与规则测试 `R038—R060`

| 轮次 | 苏晚的隐蔽干预 | 结论 |
|---|---|---|
| R038 | 只观察林默锚点日完整动线 | 建立第一份行为基线 |
| R039 | 匿名提醒他避开一次交通事故 | 能延长轮次，但不能改变他主动重启的倾向 |
| R040 | 在他忘带伞时留下伞 | 小帮助不会引发怀疑 |
| R041 | 让早餐店保留他常点的食物 | 稳定情绪只能短暂降低冲动 |
| R042 | 匿名提示某投资的正确年份 | 林默把“年份正确”误解为“现在立刻梭哈” |
| R043 | 阻断一个诈骗电话 | 他转而掉进另一项高收益骗局 |
| R044 | 远距离救下醉酒后横穿道路的他 | 被动事故可防，主动放弃更难防 |
| R045 | 完全不干预作为对照 | 轮次明显更短，确认干预有效 |
| R046 | 只改变工作选择 | 稳定工作延长生存时间，却压不住发财焦虑 |
| R047 | 只改变第一笔投资金额 | 小仓位存活更久，风险控制是关键变量 |
| R048 | 让第三方劝他记账 | 他记了三天就放弃，外部要求不能替代内在动机 |
| R049 | 让他提前避开库存生意 | 他把省下的钱投入更大的错误项目 |
| R050 | 让所有短期条件都比以往顺利 | 一次小回撤后，他仍主动结束本轮 |
| R051 | 在他饮酒前制造工作任务 | 能推迟危险时刻，不能消除根因 |
| R052 | 匿名寄送一页“历史误差清单” | 他只挑支持自己判断的部分看 |
| R053 | 让旧同事强调长期复利 | 他口头认同，行动仍追求一夜翻身 |
| R054 | 只给一条准确消息 | 单点信息成功后，他过度自信并扩大下注 |
| R055 | 给三条互相校验的信息 | 决策质量提高，但没有止损纪律 |
| R056 | 阻止一次意外死亡 | 他两天后因项目失败主动重启 |
| R057 | 不救项目，只救人 | 苏晚确认“让他活下去”比“替他赚钱”优先 |
| R058 | 试着建立普通朋友关系，不谈重生 | 林默愿意听建议，却在压力中切断关系 |
| R059 | 刻意保持完全陌生 | 没有信任，匿名建议无法改变重大选择 |
| R060 | 同时提供信息与情绪支持 | 轮次首次超过一年，最后仍因债务恐慌重启 |

## 阶段五：把轮回变成实验 `R061—R080`

| 轮次 | 实验 | 可跨轮结论 |
|---|---|---|
| R061 | 建立固定 12 页核心账本格式 | 实体不跨轮，但结构可由记忆重建 |
| R062 | 每条信息标注来源与置信度 | “听说过”不能等同于事实 |
| R063 | 重复验证比特币窗口 | 大趋势稳定，最低点日期会漂移 |
| R064 | 重复验证一只股票 | 公司事件较稳，盘中价格不稳 |
| R065 | 验证拆迁信息 | 城市规划稳，具体执行批次可变 |
| R066 | 验证早期自媒体机会 | 平台窗口稳，个人成功不自动发生 |
| R067 | 验证供应链机会 | 赚不赚钱取决于信用、交付和现金流 |
| R068 | 验证小额分散策略 | 收益慢，但显著降低林默重启冲动 |
| R069 | 验证单变量原则 | 同时改变多项会失去因果判断 |
| R070 | 验证每日复盘 | 林默若自己写，错误复发率明显下降 |
| R071 | 通过第三方让林默参与记账 | 他短期坚持，缺少共同目标时仍会放弃 |
| R072 | 测试“只成功不受挫”的路径 | 未经历回撤的成功让他更快失控 |
| R073 | 测试提前告知风险 | 知道风险不等于能承受风险 |
| R074 | 测试降低初始本金 | 小额试错更适合未来不确定性 |
| R075 | 测试分阶段兑现 | 落袋部分收益能降低全盘重启诱惑 |
| R076 | 测试普通合作身份 | 林默能合作，但会抢夺最终决策权 |
| R077 | 测试让他独立执行她的匿名方案 | 执行强，偏离计划也快 |
| R078 | 测试只给边界、不下指令 | 他的主动性更好，但需明确复盘机制 |
| R079 | 测试压力下的 24 小时冷静期 | 冷静期能避免多数冲动决定 |
| R080 | 汇总 20 轮实验 | 真正缺失的不是“神预测”，而是共同约束 |

## 阶段七：第100次，外挂才真正开始 `R100`

| 时间 | 事件 | 作用 |
|---|---|---|
| 锚点日清晨 | 苏晚在林默第一次出门前出现，准确说出 `R017` 共同事故中只有两人知道的动作与最后一句话 | 证明她不是普通预言者 |
| 当日上午 | 她连续预告三项短期小事件，并说明自己已跟随回档 83 轮 | 让林默有可验证、非盲信的证据 |
| 当日下午 | 她展示刚刚重建的 12 页核心账本结构，而不是声称旧笔记实体穿越 | 锁定记忆规则 |
| 第一次争执 | 林默本能想用重启验证；苏晚告诉他，每次重启都会抹掉她已经活过的一生 | 把重启从个人按钮变成伦理选择 |
| 合作成立 | 两人签下三条规则：不单方面重启；一次只改变一个变量；每日共同复盘 | 完整外挂形成 |
| 首次试验 | 只投入可承受损失的小额资金，经历下跌后仍按规则等待和复核 | 林默首次主动选择不重启 |
| 季终 | 第一笔可复盘盈利到账；更大的现实危机与循环来源同时露头 | “开始开挂”而非“已经暴富” |

## 轮次对照公式

从 `R018` 起，苏晚自身重生次数为：`S = R - 17`。因此：

- `R018 = S01`
- `R037 = S20`
- `R099 = S82`
- `R100 = S83`
