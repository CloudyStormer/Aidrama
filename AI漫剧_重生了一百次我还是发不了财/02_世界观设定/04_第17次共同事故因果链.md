# 第17次共同事故因果链

本文件只锁定 `R017`，任何剧本改写都不得省略中间因果。

```text
林默在R017创业失败
→ 商场突发火灾
→ 他出于本能救出本该死去的苏晚
→ 两人没有正式交换姓名，林默先离开
→ 苏晚根据有限现场线索寻找救命恩人致谢
→ 数日后她在道路附近认出林默
→ 此时林默正准备通过死亡结束本轮
→ 苏晚出于感恩和救人本能上前阻止
→ 两人的拉扯/避让进入同一辆失控车辆的事故因果链
→ 两人在同一事故窗口死亡
→ 林默死亡触发R018
→ 苏晚被共同带回2016-07-01并开始保留记忆
→ 林默仍以为这是自己一次普通重启，不知道苏晚也记得
```

## 必须保留的表演信息

- 林默救人不求回报，证明他本性善良、行动果断。
- 苏晚上前不是因为爱情，而是想感谢救命恩人并阻止眼前危险。
- 她没来得及正式自我介绍，因此林默在R018不能凭姓名寻找她。
- 苏晚只知道他的脸和有限路线线索，因此回到事故近一年前后仍需逐轮倒查。
- 事故使用呼喊、伸手、强光、刹车声、倒影和黑场表达，不展示伤口或具体撞击。

## 禁止改写

- 禁止写成苏晚火灾获救后独自遭遇车祸。
- 禁止写成林默在火灾中一救她，她就立刻自动绑定。
- 禁止让苏晚在R017之前保留重生记忆。
- 禁止让林默在R018醒来就知道苏晚也被带回。
- 禁止把苏晚的救人行为写成一见钟情式殉情。
