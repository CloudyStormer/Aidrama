# 男女主统一视觉圣经 v2

状态：`PASS`。这是用户选定方向及后续全部角色九宫格的唯一画风合同。

## 系列画风

现代中国都市题材的电影级 3D 动画，东方骨相，轻度风格化写实。角色像来自同一部高预算现代国漫电影：保留动画亲和力和清晰表情，但不走欧美家庭动画夸张脸，也不走写实游戏宣传CG的冷硬塑料感。

## 男女主共用参数

| 维度 | 唯一标准 |
|---|---|
| 头身与脸部 | 成年人约 7.2—7.5 头身；脸部轻度动画化，颅骨、下颌和鼻唇保留真实结构 |
| 眼睛 | 共用同一套东方动画写实渲染；林默保持自然明亮的男性眼型。苏晚锁定纵向开度更大的圆杏眼、较高虹膜占比、明亮自然的双层 catchlight 与下眼睑细窄泪膜水光，必须达到“大眼、水汪汪”但仍是成年女性。虹膜刻画、眼白材质和高光体系必须一致，角色差异不得演变成两种画风 |
| 皮肤 | 同一套半哑光皮肤着色，细腻但保留轻微毛孔与自然血色，不瓷娃娃、不油亮 |
| 头发 | 同一根发束精度与高光宽度，柔顺分束，不一人写实发丝、一人块状卡通发 |
| 服装 | 现代都市基础款，布料粗糙度一致，无品牌Logo、奇怪图案和身份无关装饰 |
| 镜头 | 85mm 等效人像镜头，眼平机位，头肩正脸，距离和透视一致 |
| 测试光 | 中性浅灰摄影棚；柔和主光在镜头左前45度，弱补光，克制轮廓光；5600K |
| 色彩 | 中性偏暖肤色、低饱和背景、自然对比；不让男主暖橙女主冷蓝 |
| 表情 | 中性放松，嘴角仅有角色气质差异；审批图不使用剧情性夸张表情 |
| 输出 | 同一画幅、同一裁切、同一背景、同一批次生成；先做一张双人校准板 |

## 角色-001 林默的身份差异

- 25 岁，清爽短黑发，东方男性立体骨相，眉骨、鼻梁和下颌比初稿更清晰。
- 帅气但亲近，眼神明亮，嘴角带自然开朗感；不能是欧美卡通男、冷酷霸总或长期厌世脸。
- 体型修长偏运动，不夸张健美。
- 基础服装：低饱和蓝灰圆领上衣；无眼镜、无耳饰、无纹身。

## 角色-002 苏晚的身份差异

- 22 岁，漂亮、干净、克制，东方女性柔和骨相；不是网红蛇精脸，也不是欧美游戏脸。
- 黑色长发可采用低位双束/柔和双马尾，但发根与发量自然，避免幼态校园偶像感。
- 眼神聪明、平静，带一点“已经看穿”的克制；不是反派冷笑。
- 眼睛以用户选定双人图及第四轮正脸身份卡为身份硬锚：圆杏眼须明显大于配角，棕色虹膜饱满，双眼主高光清晰，下眼睑保留自然湿润反光；侧面只按透视缩小，不得改成细长锐利眼。
- 基础服装：米白或浅灰简洁上衣；无纹身、无耳钉耳环、无脸部贴纸和额外装饰。

## 双人共同禁止项

- 画风分裂、不同渲染器观感、不同年龄美术体系。
- 皮克斯式夸张耳朵/鼻子/颅骨、欧美超级英雄下颌、游戏CG锐化脸。
- 一人磨皮瓷肤、一人真实毛孔；一人暖橙、一人冷蓝。
- Q版、儿童比例、过度大眼、网红整容脸、同脸复制。
- 纹身、耳钉、耳环、面部图案、文字、Logo、二维码、奇怪饰品。
- 角色卡白底站姿、道具和服装不得误带入剧情帧。

## 第二轮审批方法

1. 只生成一张包含林默和苏晚的双人头肩正脸校准板，二人并排、同尺寸、同背景、同灯光。
2. 先判定是否像同一部作品，再判定各自是否贴合角色。
3. 任一人不通过，整组退回；不得只保留其中一人再单独补另一人。
4. 双人正脸共同通过后，才分别扩正面全身、背面、左右侧面、左右3/4和表情锚点。
5. 正式锚点必须记录生成文件、用户审批原话、版本和允许用途。
