# AIMG 角色九宫格固定协议

状态：现行固定协议。用户要求此协议适用于本项目及今后所有 AIMG 漫剧。

| 格位 | 机器码 | 视角 |
|---|---|---|
| 左上 | V01-F0 | 正面 |
| 上中 | V02-B180 | 背面 |
| 右上 | V03-L90 | 角色自身左侧面 |
| 左中 | V04-R90 | 角色自身右侧面 |
| 中中 | V05-LF45 | 角色自身左前3/4 |
| 右中 | V06-RF45 | 角色自身右前3/4 |
| 左下 | V07-LB135 | 角色自身左后3/4 |
| 下中 | V08-RB135 | 角色自身右后3/4 |
| 右下 | V09-FULL | 正面全身，头顶至鞋底完整 |

前八格统一中长景转面裁切，第九格正面全身。每个角色单独一张图。

- 左右永远指角色自身，不指观看者。
- 左侧面鼻尖朝画面左，右侧面鼻尖朝画面右。
- 左前/后3/4均以角色自身左侧为近侧；右向视图同理。
- 后3/4必须以背面为主，不得误做成前3/4。
- 左右视图必须独立生成；禁止水平翻转、自拍镜像、`scaleX=-1` 或更换标签冒充。
- 方向错误必须重生错误视角，不得翻图修复。

九宫格生成后先在聊天中直接展示。用户逐角色或整批说“过 / 通过 / 都通过 / 就用这个”后，当前图即写入 `10_角色基准图` 根目录，成为唯一正式基准图；不再创建 REVIEW、LOCKED、版本晋级或审批子目录。未获用户确认的图不得写入10，也不得进入剧情关键帧。
