# 分镜生产与轮次HUD规则

- 镜头编号固定使用 `第001集-镜头001` 格式，不得省略集数前缀。
- 轮次变化必须出现后期 HUD；HUD 文本不交给图片模型生成。
- 每个 Clip 只承担一个主要可见动作；首尾帧分别锁定动作前和动作后状态。
- 事故、主动重启和死亡只表现决定、环境反应、强光/声音、切黑与锚点醒来，不展示具体可模仿方法或血腥结果。
- 正式人物锚点尚未通过时，分镜提示词只能写 `角色-001待锁定`，不得伪称已引用角色图。
- 正式生成顺序：连续性表 → 首帧 → 首帧验收 → 尾帧 → 尾帧验收 → 无声视频 → 单变量返工 → 声音字幕。
- 轮次蒙太奇中，构图、服装或场景每次只改变一项主变量，保证观众看得懂“同一人、不同轮”。
