# 《平行快递》世界观设定
## 基础背景
存在无数个平行世界，每个世界都有一个同名同姓的「你」，因为不同的人生选择，过着完全不同的人生：有的成了米其林厨师，有的成了亿万富翁，有的成了格斗冠军，有的成了顶级设计师。
某个时间点开始，平行世界之间出现了「快递通道」，同一个人的不同平行体之间，可以互相寄送自己拥有的东西。

## 平行快递规则
1. **时效规则**：每天最多收到1个快递，固定早上7点准时出现在家门口，不会早也不会晚。
2. **寄件规则**：寄件人永远是「另一个我」，没有寄件地址，没有快递单号，只有普通的牛皮纸快递盒，上面用黑色签字笔写着收件人名字。
3. **内容规则**：快递里只能是平行世界的自己**真实拥有**的东西，不能凭空捏造：
   - 技能类：厨艺、格斗、设计、口才、理财等永久技能，收到之后自动融入记忆，直接就会用
   - 物品类：钱、衣服、菜谱、工具等实物，拆盒直接能用
   - Buff类：一天好运、社牛一小时、不困buff等临时增益，有明确的时效
   - 记忆类：某段经历、某个知识、某个人的信息等
4. **适配规则**：所有快递内容都会自动适配当前世界的规则，比如寄过来的钱会自动变成当前世界的合法货币，不会出现假钱、来路不明的钱。
5. **双向规则**：前期只能收快递，后期能力变强之后，也可以给其他平行世界的自己寄东西，互相帮忙。

## 限制与反噬（避免金手指太bug）
1. **不能超常识**：不会寄来修仙、魔法、毁天灭地的超能力，所有内容都是正常人类能拥有的能力和物品
2. **不能做坏事**：如果用快递获得的能力/物品做违法、害人的事，所有已获得的能力会立刻被收回，快递通道永久关闭
3. **不能公开**：不能告诉任何人平行快递的存在，说了别人也不会信，还会导致当天的快递失效
4. **数量限制**：每天只能收一个，不会多给，也不会因为你特别需要就提前寄来

## 长线悬念（第一季铺垫，后续揭开）
1. 为什么突然出现平行快递？是谁开启的通道？
2. 为什么所有平行世界的自己都在给主角寄东西？
3. 平行世界的自己是不是都遇到了共同的麻烦，需要主角的帮助？
4. 一共有多少个平行世界的自己？

## 快递视觉设定
- 外观：普通棕色牛皮纸快递盒，大小随内容变化，小到戒指大到家电都能装，重量永远很轻
- 拆盒效果：拆开的时候会有淡淡的金色光粒散开，技能类会直接钻进主角额头，物品类直接出现在盒子里
- 消失：拆完之后的空盒子会在10分钟后自动消失，不留任何痕迹
