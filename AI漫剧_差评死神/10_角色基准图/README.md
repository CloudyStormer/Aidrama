# 《差评死神》角色基准图标准

## 统一风格

全部使用精致2.5D/3D国漫电影级渲染，真实东亚面孔，骨相立体、轮廓清楚、帅气养眼；皮肤保留自然纹理，头发有发束，服装有布料质感。禁止二维平涂、Q版、塑料脸、蜡像脸、夸张网红妆。

男角色必须帅气养眼但各有骨相：许言是带泪痣、银灰额发和疲惫黑眼圈的冷峻故事感；周牧是宽额头、鹰钩鼻和灰鬓角的成熟压迫感；赵启是宽下颌、短寸头的阳光硬朗感。女角色必须美丽动人但各有辨识点：唐小满是高颧骨、上挑凤眼与不对称短发的英气明艳；小鹿是圆眼和薄唇的清秀脆弱；方姨是自然笑纹与圆脸的亲切成熟。任何两人不得共用脸型、眼型、眉形、鼻唇比例或同一套年龄纹理。

本项目角色不得沿用《打工人逆袭》的视觉母版：禁止男主黑框眼镜、蓝格衬衫、普通顺直短发组合；禁止女主普通齐肩短发、休闲衬衫与牛仔裤组合。角色基准图必须从独立造型描述生成，不以旧项目角色图作为参考。

## 必备角度

高频角色许言、唐小满、周牧各生成：

1. 正脸头肩；
2. 左3/4侧脸头肩；
3. 右3/4侧脸头肩；
4. 正面全身；
5. 剧中常用表情锚点（许言警觉、唐小满坚定、周牧平静压迫）。

赵启与方姨各生成正脸、左3/4侧脸、右3/4侧脸、正面全身。小鹿与老人家属按出现镜头补正脸和一个3/4侧脸即可。

## 锁定规则

- 后续关键帧按人物朝向选最接近的基准图作为身份参考。
- 同框时分别提供每名角色的基准图，提示中逐一写明角色位置和服装。
- 只锁身份与造型，不照搬基准图背景和站姿。
- 所有皮肤区域绝无纹身、贴纸、符号；不自动添加首饰或其他配件。
