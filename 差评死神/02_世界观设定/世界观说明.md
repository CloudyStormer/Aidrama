# 《差评死神》世界观设定
## 基础背景
现代普通都市，表面和现实世界完全一样，996、加班、被客户刁难、遇到奇葩是常态。但所有被欺负、被损害的人，手机里都会悄悄出现一个只有自己能看见的隐藏小程序——「阴间差评」。

## 差评系统规则
1. **触发条件**：只有当对方确实做了损害你利益、欺负你、给你造成痛苦的事时，你才能给他打差评，恶意诬陷的差评直接无效，还会反噬打差评的人。
2. **积攒规则**：每被对方欺负一次可以打1个差评，攒够100个有效差评，系统就会自动召唤死神上门收走对方。
3. **时效规则**：单个差评有效期24小时，24小时内没攒够100个，差评自动清零，下次被欺负重新攒。
4. **匿名规则**：打差评全程匿名，被差评的人完全不知道是谁打的，也看不见这个小程序。
5. **普通人限制**：普通人只能给自己欺负过自己的人打差评，不能帮别人打，一个人最多同时给3个人攒差评。

## 死神设定
1. **形象**：死神不是恐怖的骷髅，是穿黑色机能风衣、拿发光电子镰刀的酷飒男性（后续可以出女死神单元），话少、效率高、面冷心热，只按规则办事，不滥杀无辜。
2. **职责**：只收被打满100个差评的坏人，不伤害好人，把人拉进专属「罪罚异空间」执行惩罚。
3. **能力**：可以瞬间移动、隐身、把人拖进异空间、定制专属惩罚，普通人看不见死神，也看不见惩罚过程，只会觉得被惩罚的人突然发呆/晕倒，醒过来以为自己做了个噩梦。

## 罪罚异空间&惩罚规则
1. **异空间设定**：每个被惩罚的人都会进入专属的罪罚异空间，空间场景完全对应他欺负人的场景：比如加班的领导就进永远不下班的办公室，改方案的客户就进永远改不完的设计室。
2. **惩罚核心原则**：**对等加倍**——他怎么欺负别人的，就怎么在他身上加倍还回去，让他完整体验到被他欺负的人的痛苦。
3. **惩罚时长**：根据恶劣程度从3小时到3个月不等（异空间时间和现实时间流速不同，异空间3天现实只过3分钟），惩罚结束自动把人放回现实，不会真的受伤，但会留下真实的心理阴影，再也不敢欺负人。
4. **惩罚示例**：
   - 让员工无薪加班的领导→异空间里永远在加班，键盘敲到冒烟，永远到不了下班时间，老板还在旁边一直催
   - 让设计师改100版方案的客户→异空间里永远在改方案，永远是“还是第一版好”“再改改”“不够大气”
   - 地铁咸猪手→异空间里永远在挤地铁，被无数只手摸，动都动不了
   - 熊家长纵容孩子捣乱→异空间里永远被熊孩子拆家、闹、砸东西，管都管不住
5. **惩罚限制**：不会真的打死人、打伤人，只会造成精神痛苦和心理阴影，惩罚结束人完好无损回到现实，就是再也不敢干坏事了。

## 主角金手指
主角林默是阴间差评系统在人间的唯一代理人：
1. 能看见所有人头顶的差评进度条，谁被谁欺负了、还差多少个差评满，一眼就能看见
2. 可以帮所有受欺负的人补差评，别人攒100个才能召唤死神，主角只要打1个有效差评，就能直接召唤死神上门
3. 能和死神沟通，定制惩罚的具体内容，保证惩罚精准戳痛点
4. 不会被系统反噬，只要是惩罚坏人就不会有副作用

## 系统限制（避免金手指太bug）
1. 绝对不能给好人打差评，不能用能力谋财、害人、报私仇，否则会被系统收回能力，自己被拉进异空间受罚
2. 不能暴露系统和死神的存在，和别人说也没人信，还会被系统警告
3. 不能干涉普通人的正常生活，只能在有人被欺负的时候出手
4. 惩罚不能致死、致残，只能给教训，点到为止
