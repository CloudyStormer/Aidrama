# AI漫剧提示词规范与标准模板

> 2026-07-25 制作升级：从第2集开始统一按“每集18镜头 × 每镜头5秒 = 90秒”生产。第2—8集共126个镜头，成片基础时长630秒（10分30秒）。

## 零容忍画面约束（生图、图生视频均须逐镜复制）

人物身份、脸型、五官、发型、年龄、服装颜色和体型必须与对应角色基准图一致；场景的时间、地点、光源和道具必须与分镜一致。只允许分镜明确写出的角色与物品出现。

**绝对禁止：**任何人物皮肤出现纹身、刺青、贴纸、奇怪符号或不明图案；香烟、烟头、烟雾、电子烟、雪茄、打火机、酒瓶、酒杯；纸张、灰尘、粒子、碎片或道具无原因漂浮、飞舞；反重力物体；不符合办公室场景的霓虹灯、赛博朋克装饰、武器、首饰、帽子；多余人物、多余手脚、多余手指；服装瞬变、脸部漂移、背景跳变；文字、水印、logo、二维码。

除非分镜明确要求，桌面只保留电脑、键盘、鼠标、单一文件夹和水杯中的必要项；地面、空中和人物身上不得自动添加任何装饰或杂物。室内无风，纸张必须平放或由人物真实持握，不得飘动。

## 收紧版图生视频母提示词

```text
仅将上传的单张关键帧动画化，不重绘、不换脸、不换装、不改变场景、不新增角色或道具。保持人物身份、五官、发型、年龄、体型、服装、空间布局、光线方向和画面构图从第1帧到最后1帧完全一致。全片只完成一个明确的小幅动作，动作起点、过程和终点连续自然；眨眼最多1次，嘴部仅在有台词时小幅自然开合，手指数量与关节始终正常。镜头按分镜要求固定或仅做不超过5%的缓慢推近/拉远，不摇晃、不跳切、不突然变焦。室内空气静止，纸张和所有道具遵守重力并留在原位。禁止纹身、烟、烟头、烟雾、电子烟、酒、火焰、漂浮物、飞散物、粒子、凭空出现或消失的物品、多余人物、多余肢体、脸部漂移、服装变化、背景变形、穿模、闪烁、果冻感、抽搐、夸张大动作、跑跳、转圈。9:16竖屏，连续5秒，24fps，单一连续镜头，只生成1个视频。
```

## 时长验收

- 第2—8集每集必须完整生成18条、每条5秒，任何失败镜头都应重做，不得用静帧缩短。
- 7集素材合计：`7 × 18 × 5 = 630秒 = 10分30秒`。
- 剪辑时镜头不得加速；对白较长时可保留5秒画面并让配音跨镜衔接。
- 转场使用0—2帧硬切，不以转场覆盖镜头有效时长。
## 一、核心原则：锁一致性
所有提示词必须严格按照公式拼接，保证全剧画风、人物、场景100%统一，避免AI生成崩坏。
## 二、标准提示词公式
```
【通用风格前缀】+【角色固定提示词】+【场景固定提示词】+【当前镜头描述（景别+动作+表情+光线）】+【负向提示词】
```

## 九、生成参数规范
- 比例：抖音/快手用9:16（1080×1920），B站用16:9（1920×1080）
- 视频时长：所有片段固定15s，和工具限制对齐
- 图生视频运动幅度：小幅度运动（人物表情变化、镜头缓慢推拉），避免大幅度动作导致人物崩坏
